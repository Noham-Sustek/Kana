# EmptyState

Ce qu'on montre quand il n'y a encore rien : une case vide en pointillés, un titre, une phrase, une action.

- La case reprend le motif du système : elle attend d'être remplie. Pas d'illustration figurative.
- Le titre dit l'état sans reproche (« Aucune liste pour l'instant »). La phrase dit à quoi servira l'écran. Le bouton mène à l'action qui le remplit.
- Un seul bouton. Principal si c'est l'action attendue de l'écran, contour sinon.

Vous fournissez l'icône, le titre, la phrase, l'action.
