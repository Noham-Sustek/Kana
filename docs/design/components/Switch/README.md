# Switch

Réglage oui / non à effet immédiat (`role="switch"`).

- Toute la ligne est la cible. Le libellé dit ce qui se passe quand c'est activé ; la description, facultative, dit ce qui se passe sinon.
- Activé : piste `accent`, curseur à droite portant une coche. Désactivé : piste `paper-raised`, curseur `border-control` à gauche.

Vous fournissez `label`, `description`, `checked`, `onChange` (signature de `Switch.tsx` inchangée).
