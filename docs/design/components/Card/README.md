# Card

Surface `paper-raised` bordée d'un filet, sans ombre.

- **Simple** (`k-card`) : regroupe une information. Filet `hairline`.
- **D'action** (`k-card--act`) : toute la carte est un bouton, contour `border-control`, icône `accent` à gauche, chevron à droite, 68 px minimum.
- **Sélectionnable** (`is-sel`) : contour `accent` 2 px, fond `accent-tint`, bouton radio coché.
- Ne mettez pas de carte dans une carte. Une section de page se sépare par un filet (`k-hr`) et un intitulé `overline`, pas par une carte.

Vous fournissez l'icône, le titre, une ligne de détail.
