# Banner

Message discret, non bloquant, posé dans le flux de l'accueil ou des réglages.

- Un seul bandeau à la fois sur l'accueil, sous le contenu, jamais au-dessus du bouton principal.
- Une phrase, une action en lien souligné, une croix pour masquer. Masqué = ne revient pas avant 30 jours (sauvegarde) ou plus jamais (installation).
- Pas de couleur de signal : contour `border-control`, fond `paper-raised`.

Vous fournissez l'icône, la phrase, le libellé de l'action.
